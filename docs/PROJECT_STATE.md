# 项目当前状态

本文档只记录仓库中已经存在的代码事实，不记录计划完成但尚未实现的功能，
也不把未执行的测试写成已验证结果。

## 当前目标

输入：

- `base_pose`：机械臂基座在绝对坐标系中的位姿；
- `target_point`：末端目标点在绝对坐标系中的位置；
- `/joint_states`：Elfin5 当前关节位置。

输出：

- 满足关节位置、速度和加速度限制的短时域关节轨迹；
- 末端位置误差、平移雅可比最小奇异值和控制器状态；
- 到达目标点、奇异恢复、输入异常和QP异常的明确状态。

当前阶段只要求末端安全到达目标点，不约束末端姿态，不包含全局路径规划、
环境避障、夹爪控制和抓取执行。

## 当前数据链路

```text
base_pose + target_point + joint_states
                    ↓
          输入有效性与超时检查
                    ↓
 T_absolute_base⁻¹ × p_absolute_target
                    ↓
             target_point_in_base
                    ↓
 MoveIt RobotState：FK + Jacobian参考坐标转换
                    ↓
          base_link坐标中的3×N Jv
                    ↓
     最小奇异值、恢复方向和关节居中项
                    ↓
       带关节边界与奇异约束的速度QP
                    ↓
          单点短时域 JointTrajectory
                    ↓
       /elfin_arm_controller/command
```

## 已实现代码

- 从 `robot_description` 加载MoveIt机器人模型；
- 从规划组读取关节名称、位置边界和速度边界；
- 按关节名称重排 `/joint_states`，不依赖消息中的数组顺序；
- 根据关节位置计算末端正运动学和3×N平移雅可比；
- 将绝对目标点转换到机械臂基座坐标系；
- 通过参数 `base_link` 明确外部基座位姿对应的URDF链接，默认使用
  `elfin_base_link`；
- 将末端FK从MoveIt模型坐标系转换到 `base_link`；
- 将MoveIt Jacobian从规划组首关节父链接 `elfin_base` 旋转到
  `elfin_base_link`，保证位置误差和Jacobian坐标轴一致；
- 计算平移雅可比最小奇异值；
- 使用中央差分计算常规奇异值梯度；
- 中央差分在精确奇异点退化时，使用单侧扰动构造恢复方向；
- 根据关节位置、速度和加速度限制生成QP变量上下界；
- 使用自适应阻尼、关节居中速度和奇异规避半空间；
- 使用Eigen实现盒约束加单个半空间约束的投影梯度QP；
- 区分QP“结果可行”和“优化已收敛”两个状态；
- 统一关节位置积分时间与 `time_from_start`；
- 检查三类输入的新鲜度、有限数和绝对坐标系名称；
- 收到禁用请求时发布一次当前位置保持命令，之后停止QP命令输出；
- 启用服务在三类输入缺失、过期、关节名不完整或坐标系错误时拒绝进入闭环；
- 输入等待、输入过期、运动学失败和QP失败时持续发布当前位置保持命令；
- 使用互斥锁串行化RobotState和控制器历史速度的访问；
- 发布位置误差、最小奇异值、QP迭代次数、QP残差和控制器状态。
- 控制器未enable时仍发布当前末端绝对坐标和最小奇异值，便于先观察再选目标；
- QP最大迭代次数和收敛容差可通过YAML调整。
