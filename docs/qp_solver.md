# QP算法与数值验收

## 问题与范围

```text
min  0.5*xᵀ*H*x + gᵀ*x
s.t. lower <= x <= upper
     aᵀ*x >= b     （可选，至多一个）
```

H的对称部分必须正定，所有输入和边界必须有限，维度非空且一致。机械臂用x表示六轴速度；求解器本身支持其他维度。不支持一般多半空间、动力学WBC或姿态层级QP。

solve参数与QPSolution结构保持兼容。无约束的三维平移任务通过阻尼项和偏好速度正则化，不是严格任务优先级：关节居中、活跃边界和奇异半空间会影响最终速度及后续轨迹。

## 算法

1. 检查输入、上下界和H的正定分解；不能分解或数值溢出明确返回失败。
2. 有半空间时，先按最大系数及二范数归一化a、b，不用绝对小法向阈值丢弃约束。a完全为零时，b>0不可行，b<=0恒真。
3. 在盒上计算aᵀx的支持值，判断半空间是否有可行交集；只允许浮点舍入量级的支撑面修正。
4. 使用原始有效集求盒QP：在自由变量上Cholesky求最优点，沿可行方向移动到阻挡边；检查边界乘子符号，必要时释放。l=u的固定变量不释放。
5. 如果盒最优解违反半空间，令g变为g−μa、μ>=0。扩大乘子区间获得可行上端点，之后使用区间内的牛顿候选，否则二分。导数来自该端点自身的有效集；未求完子问题不会用来更新区间。
6. 检查原问题的可行性、驻点符号、乘子非负及互补残差。找到可行解与证明容差内收敛分开报告。

所有有效集步骤共享max_iterations总预算，iterations不会超过配置值。预算限制的是有效集步骤，不是CPU时间；线性分解、证书与乘子导数计算仍有耗时。预算不足不是数学不可行证明。

## 结果与残差

- success：有限、无已检测数值失败且约束在容差内可行；不代表最优或硬件执行安全。
- converged：还要求最后采用的盒子问题完成，并满足完整归一化KKT容差。
- iterations：本次solve累计有效集步数。
- projected_gradient_norm：兼容名称，保存无量纲KKT残差；不再是旧的投影梯度值。历史诊断不可直接混比。
- message：中文，区分不可行、输入错误、预算/精度限制与数值失败。
- 上层QP_INFEASIBLE是已有通用失败状态，应结合message判断原因。

令a已归一化、r=Hx+g−μa。证书取下列量的最大值：
- 盒原始违反量：每轴违反量除以1+max(|lower|,|upper|)；
- 半空间违反量：max(0,b−aᵀx)/(1+|b|)；
- 驻点量：自由变量取|r|，下界取max(0,−r)，上界取max(0,r)，固定变量不限制r；最大值除以1+||Hx||∞+||g||∞+|μ|*||a||∞；
- 乘子非负违反量：max(0,−μ)/(1+|μ|)；
- 互补量：|μ*(aᵀx−b)|/(1+|0.5*xᵀHx|+|gᵀx|)。

乘子搜索内部还要求半空间边界误差达到更紧精度，避免小乘子使互补量很小、但边界误差仍偏大。浮点条件数和尺度仍影响数值可靠性，不能称为不受条件数影响的数学精确算法。

## 固定回归与来源

test/qp_reference_cases.txt逐字节保留用户提供的2000例参考集，SHA256及已知/未知版本见meta.json。三组分别667、667、666例，覆盖一般问题、弱曲率问题、控制器形态问题。参考值由原作者SLSQP产生；回归另外独立检查原始约束、绝对目标差及KKT，不只相信求解器状态。

这是合成可行问题集。法向/偏置不是实测奇异值梯度，错误比例不代表真机故障率；不可行、零法向、缩放、固定变量、空输入、非有限和预算不足由解析用例覆盖。

## Ubuntu独立复现

仓库根目录：

```bash
g++ -std=c++14 -O2 -Wall -Wextra -Wpedantic -I include -isystem /usr/include/eigen3 \
  src_gazebo/box_qp_solver.cpp test/test_box_qp_standalone.cpp -o /tmp/elfin5_qp_test
/tmp/elfin5_qp_test test/qp_reference_cases.txt 2000
python3 test/test_qp_input_files.py /tmp/elfin5_qp_test
```

程序先执行40项解析断言，然后严格读取期望数量的完整记录。检查有限性、盒/半空间、收敛、总预算、双向目标差和独立KKT。随机集目标差要求abs(f−f_ref)<=1e-7*max(1,|f_ref|)，不是只比较正差。缺失、空、截断、额外字段、NaN或数量不符均非零退出。

运行新种子（开发机额外安装NumPy/SciPy，不是ROS节点依赖）：

```bash
python3 scripts/gen_qp_reference_cases.py --seed 43 --count 2000 --output /tmp/elfin5_seed43.txt
/tmp/elfin5_qp_test /tmp/elfin5_seed43.txt 2000
```

生成器拒绝覆盖已有文件。SLSQP参考解需通过原始约束及非负乘子KKT校验，记录版本、seed、尝试/拒收次数、分组和SHA256；不同库版本不保证生成文件逐字节一致。多种子压力测试不能替代真实QP输入回放。

## 仿真验收衔接

固定相同初始姿态、目标和增益，独立记录旧/新版本。先R1，再R1–R3，最后R1–R9各重复3次。不要为了得到旧曲线先改joint_centering_gain。

记录末端误差、关节命令/反馈、关节离中位距离、sigma最小值、状态和求解/整回调时序。可行未收敛占比只是辅助诊断。准确求解后关节居中可能更明显，末端及奇异区轨迹也可能改变；无约束情况下的零空间分解不能推广为活跃约束下的完全跟踪。

R1–R4按各自到达/约束验收，R5/R6按奇异区到达/改善，R7/R8使用对应允许安全终态，R9检查超时处置。任何仿真通过仍不构成真机授权。
